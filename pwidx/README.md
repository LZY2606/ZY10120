# pwidx — 一维粉末衍射晶格索引候选服务

`pwidx` 是一个**自包含**的粉末衍射（powder diffraction）晶格索引（indexing）工具：
输入一维 2θ 或 d-spacing 峰位列表、峰位不确定度、可选强度与波长，再给定晶系范围、
体积上限和系统消光规则，系统生成、评分并解释**若干候选晶格**。

它**不连接任何外部晶体库**，也不会报出一个“看似精确的唯一答案”——
输出始终是带证据、残差和歧义标注的候选集合，由人来比较、锁定与派生。

- 语言/依赖：Go 1.22+；唯一第三方依赖为纯 Go 的 `modernc.org/sqlite`（**无需 cgo**）。
- 状态：SQLite（作业、冻结候选、峰排除覆盖、锁定、比较集）。
- 求解器：确定性随机种子；候选排名与并行度无关。
- 页面：峰位/hkl 对照杆图、匹配表、未解释峰、预测缺失峰、候选比较。

## 安装与演示

```bash
go mod download
go test ./... -count=1
go run ./cmd/server --listen 127.0.0.1:5320
```

打开 <http://127.0.0.1:5320>，在首页“合成 fixture”中选择例如
`cubic_F_NaCl_like`，点击“提交求解”即可看到带噪声合成图样的完整流程。

参数：

- `--listen`：监听地址（默认 `127.0.0.1:5320`）。
- `--db`：SQLite 路径（默认 `./pwidx-state.db`）。

## 单位与约定

| 量 | 单位 |
|---|---|
| 峰位输入（`unit=two_theta`） | 2θ，度（°），开区间 (0, 180) |
| 峰位输入（`unit=d`） | 面间距 d，埃（Å），正数 |
| 波长 λ | 埃（Å，Cu Kα = 1.5406） |
| 晶格参数 a,b,c | 埃（Å） |
| 角度 α,β,γ | 度（°） |
| 体积 V | Å³ |

物理关系：`d = λ/(2·sinθ)`；对任意晶系 `1/d²(hkl) = vᵀ G* v`，
其中 `G*` 为倒易度量张量（正度量张量求逆得到，避免在各晶系统一式里抄错符号）。

峰位不确定度可以按峰给：

- 2θ 输入时 `σ` 单位为度；省略时默认 0.05°。误差传播：`σ(d) = d·cotθ·σ(2θ)`（弧度换算在内）。
- d 输入时 `σ` 单位为 Å；省略时默认 `σ = 0.002·d`。
- 匹配使用组合不确定度：`σ_eff = sqrt(σ_obs(d)² + (0.0005·d_pred)²)`，
  归一化残差 `z = (d_pred − d_obs)/σ_eff`。

文本输入格式（每行一条）：

```
28.45,0.03,100
32.96,0.03,62.4
47.31,0.04
```

即 `位置[, 不确定度[, 强度]]`，分隔符可为逗号、分号、空白。

## 标准形（canonical reduction）

同一晶格可以用等价轴置换、等价晶胞选择描述。若不约化，Top-K 会被同一晶格的
各种写法占满。`internal/canonical` 在发布前对每个候选做稳定标准形约化：

- **立方**：无自由度，保持。
- **四方/六方**：保持 `(a,a,c)` 与六方 `γ=120°` 约定。
- **正交**：等价轴置换排序为 `a ≤ b ≤ c`（置换记录在打分中，hkl 展示始终基于标准形胞）。
- **菱方**：取 `α = min(α, 180°−α)`（短/长菱面体等价）。
- **单斜**：唯一非直角取为 `β ≤ 90°`；在保持 b 轴约定下做有界剪切 `a' = a + m·c`。
- **三斜**：枚举 `|u_ij| ≤ 1`、`det U = ±1` 的全部整数幺模变换 GL(3,Z)，
  在变换后的胞中选择确定性词典代价最小者（轴长升序、|非对角项| 升序……）。

这是一种**有界、确定性、自包含**的 Minkowski/Delaunay 风格短向量约化，
不是完整 Niggli 约化；在高指数（默认 hkl≤6）范围内稳定，边界情况可能存在
等价但不同形的胞，因此它被当作**去重约定**而非“数学唯一约化胞”，
这一点同时写入 README 与每次作业的计算清单。

去重键为 `晶系统 + 参数相对量化（1e-5 相对精度）`；同键只保留排名最高的候选。
**排序本身不使用量化值**——同分比较键使用未四舍五入的完整参数（见下）。

## 候选如何产生

1. **解析建议**（单线程、确定顺序）：
   - 立方：`a = d·√N`，枚举 `N = h²+k²+l²`；先按消光规则过滤 hkl。
   - 四方/六方：从 `(h00)` 与 `(00l)` 系峰反算 `a,c`。
   - 正交：前若干低角峰中选 `(h00)/(0k0)/(00l)` 三轴组合。
   - 菱方：用 `(hhh)` 与 `(h,-h,0)` 峰对解 `a,α`。
   - 单斜：用 `(h00)/(00l)/(h0l)` 解 `a,c,cosβ`。
   - 三斜：前 6 峰的 720 种排列映射到 `(100),(010),(001),(110),(101),(011)`，解全部度量分量。
2. **受控随机建议**：按种子（默认 42）为低对称晶系生成确定性随机起点，
   覆盖解析组合没命中的情况。所有随机建议在**任何并行开始之前**于单线程生成完毕。
3. **预筛 + 精修**：对全部建议做一次粗评分，每晶系取前 12 个进入
   Nelder–Mead 单纯形优化（默认每建议最多 50 次目标评估，约束轴/角联动）。
4. **约化、去重、排序、截断 Top-K**。

## 评分组成（排名而非概率）

综合分数（越大越好）：

```
score = 2.0 · coverage            # 已解释非排除峰占比
      − 3.0 · rms_z               # 全部主匹配的归一化残差 RMS
      − 0.5 · missing/n_groups    # 观测窗内“预测却缺失”反射比例
      − 1.0 · unexplained/n_used  # 未解释峰比例
      − 0.05 · parsimony          # 晶系自由度：立方0 … 三斜4
```

`score` 只用于排序，**不能解释为“正确概率”**。候选页展示每个分项与全部证据。

匹配与证据规则：

- **峰→hkl 分配**：互斥贪心（先满足最小 |z| 的峰-组对，z≤3 才算匹配）；
  同一预测组的简并 hkl 全部列在该峰下，主匹配加粗，`ambiguous` 显式标注。
- **歧义**：一个观测峰在歧义窗（z≤3）内对应多个反射/反射组时，候选页列出全部候选 hkl 及各自残差；
  歧义不直接扣分，而是同分次级排序键。
- **系统消光**：反射在进入预测表之前就按规则过滤，**被排除的 hkl 不可能作为匹配证据**。
  支持 P/I/F/C/A/B/R 格子与代表性螺旋轴/滑移面/金刚石型规则（见页面下拉与 `/api/extinctions`）。
- **未解释峰**：观测窗内没有任何允许反射落入匹配带的非排除峰。
- **预测却缺失**：观测窗内允许、且未被任何峰（含歧义引用）覆盖的预测反射；
  同时给出最近的观测峰及残差，若最近峰是被用户排除的，会明确标注。
- **排除覆盖**：在候选页切换某峰的排除标记会写入独立覆盖层并可派生重算，
  **原始峰表永不改动**；派生作业是新作业、新指纹、新候选集合。

### 同分比较键（tie-break）

当两个候选 `score` 相等时，依次比较：

1. `coverage` 高者优先
2. `rms_z` 低者优先
3. `explained` 多者优先
4. `ambiguous` 少者优先
5. `missing` 少者优先
6. 晶系自由度低者优先（更简单的晶格）
7. 标准形参数字典序（`a,b,c,α,β,γ`，未四舍五入）

比较键、权重、容差、量化策略、随机种子与尝试数都会写进**可导出的计算清单**
（作业页“下载计算清单”或 `GET /api/jobs/{id}/manifest`）。

## 确定性与并行度无关性

- 随机建议在单线程内按种子一次性生成；顺序固定。
- 打分 `Evaluate` 是无随机纯函数；精修也是确定性的（Nelder–Mead 无随机数）。
- worker 只把“固定顺序的建议”并行处理，结果写回各自预分配槽位；
  去重与排序在主流程单线程完成。
- `workers` 不进入输入指纹。测试 `TestParallelismInvariance` 对比 workers=1/8
  的完整候选键与分数。

## 作业模型、幂等与中止

- **幂等提交**：作业以输入（峰、单位、波长、晶系、体积、规则、种子、求解参数）的
  SHA-256 **指纹**标识；重复 `POST /api/jobs` 返回同一作业。
  峰排除覆盖不参与根作业指纹（派生作业独立标识）。
- **中止**：`POST /api/jobs/{id}/cancel`。检查取消发生在建议生成与每个精修任务边界；
  中止的作业状态为 `aborted`，**不发布半成品 Top-K**，候选表为空。
- **恢复**：进程退出时仍在运行的作业，在下次启动时统一标记为 `aborted`
  （不会自动重跑，避免静默改变结果）；客户端可用相同输入重新幂等提交。
- **冻结**：候选 JSON 连同当时的消光规则与 `algorithm_version` 整行写入 SQLite。
  锁定只是加标记；派生总是产生新作业，旧候选引用的规则/算法版本永不变更。
  任何改变打分或几何的修改都必须提升 `diffract.AlgorithmVersion`。

## 输入状态与边界情况

校验层（`diffract.Normalize`）对以下情况给出明确 `code` 与状态（`ok`/`error`，
问题同时显示在页面并随作业保存）：

- `empty_peaks`：零峰列表。
- `out_of_range` / `bad_d`：2θ 不在 (0,180)° 或 d 非正。
- `arcsin_domain`：`λ/(2d)>1`（2θ 无实数解）。2θ 输入直接判错；
  d 输入时保留该峰用于 d 空间索引，但标注它在该波长下不可观测。
- `non_finite`：峰位为 NaN/Inf。
- `duplicate_peak`：位置重复的峰（两条都保留，提示确认是否重复导入）。
- `bad_wavelength` / `bad_unit`：波长非正或单位未知。
- 体积超上限的建议在精修前与发布前各过滤一次。

## 合成 fixture

`internal/fixtures` 内置 6 个确定性图样（NaCl 型 F 立方、金红石型 P 四方、
石墨型 P 六方、镁橄榄石型正交、方解石型菱方、一般单斜），
由理论反射加按种子控制的 2θ 抖动、随机缺峰与杂峰生成，用于演示和测试；
生成函数本身确定性，可用于回归。

## 目录结构

```
cmd/server/            HTTP 服务入口
internal/diffract/     物理层：胞参数、度量张量、Bragg、反射枚举、输入校验
internal/extinction/   系统消光规则
internal/canonical/    标准形约化与去重键
internal/solver/       建议生成、确定性精修、纯函数评分、排名与清单

```

## 局限与诚实边界

- 三斜约化是有界枚举约定，不是完整 Niggli；建议生成依赖低指数峰组合，
  强择优取向、严重峰重叠或首峰被错误排除时可能需要降低晶系期望并重试。
- 零位偏移（zero-shift）未作为自由参数拟合；请在校验确认后再提交。
- 评分是工程排序启发式，不提供不确定度区间或空间群判定——消光规则是用户给定的假设。
